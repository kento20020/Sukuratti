# Sururashi — バナナスクラッチチャンス 🍌

スクラッチチャンス。銀色の面を指やマウスでこすると、バナナが出てくるスクラッチくじです。
決済アプリ（PayPay）のスクラッチくじ風の赤×白 UI で、**HTML / CSS / JavaScript だけ**で動きます。
サーバーもビルドも不要なので、GitHub Pages にそのまま公開できます。

## 主な機能

- **6種類のスクラッチ**（ホームから選べます）
- **13種類のバナナ**（ハズレ / N / R / SR / SSR / UR）。図鑑で集められます
- **バナナごとに違う当たり音・ハズレ音**。Web Audio API で合成しているので音声ファイルは不要です
- こするときの「シャリシャリ音」、リーチ音、ドラムロール、確定演出の「キュイーン」音
- 紙吹雪・回転する光・フラッシュなどの当たり演出（レアなほど豪華）
- 確定演出：SSR 以上のときは、削る面が金色や虹色になることがあります
- 図鑑・履歴・設定（サウンド / 音量 / 読み上げボイス / バイブ / サウンドルーム / リセット）
- 引きかけのカードは「つづきから」再開できます（リロードによる引き直しはできません）
- スマホのタッチ、マウス、キーボード（Enter / Space）で操作できます。`prefers-reduced-motion` と ダークモードにも対応しています

### スクラッチの種類

| カード | 料金 | 内容 |
| --- | --- | --- |
| おためしバナナくじ | 無料（何度でも） | 1マス。出たバナナのポイントがもらえる |
| きょうのバナナくじ | 1日1回無料 | R 以上確定・ハズレなし。毎日0時に回数が戻る |
| バナナスロット | 5pt | 3マス。3つそろうとポイント×10。2つそろうと「リーチ！」 |
| 6マスそろえてバナナ | 10pt | 6マス。同じバナナ3つでポイント×3 |
| えらんで3つ！バナナハント | 20pt | 9マスのうち好きな3マスだけ削れる。3マスの合計ポイント |
| ゴールデンジャンボ | 100pt | 金色の大きなスクラッチ。ハズレなし・SSR 以上が出やすい |

各カードの「提供割合」リンクから、出現確率を確認できます。

## GitHub Pages で公開する

1. このリポジトリの **Settings → Pages** を開く
2. **Build and deployment** の Source を「**Deploy from a branch**」にする
3. Branch で公開したいブランチ（例：`main`）と `/ (root)` を選んで **Save**
4. 1〜2分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べます

`.nojekyll` を置いてあるので、Jekyll の変換はされずにそのまま配信されます。

## 手元で動かす

`index.html` をブラウザで直接開くだけでも動きます。ローカルサーバーで動かす場合は次のとおりです。

```bash
python3 -m http.server 8000
# → http://localhost:8000/ を開く
```

## テスト

抽選ロジック（確率・そろい判定・ポイント計算）と保存処理のテストです。Node.js 18 以上で実行できます。

```bash
npm test
```

GitHub Actions（`.github/workflows/test.yml`）でも push のたびに実行されます。

## ファイル構成

```
index.html            画面の骨組み
assets/css/style.css  デザイン（赤×白のアプリ風 UI）
assets/js/bananas.js  バナナ13種のデータと SVG イラスト
assets/js/cards.js    スクラッチ6種の定義と抽選ロジック
assets/js/storage.js  ポイント・図鑑・履歴の保存（localStorage）
assets/js/sound.js    効果音（Web Audio API で合成）と読み上げ
assets/js/effects.js  紙吹雪・フラッシュ・バイブ
assets/js/scratch.js  こすって削る Canvas コンポーネント
assets/js/app.js      画面遷移と各画面
tests/logic.test.js   抽選と保存のテスト
```

## 注意

- ポイントは遊び用の架空のものです。現金・電子マネー・実在の決済サービスとは一切関係ありません。
- このサイトは非公式のファンメイド作品です。PayPay 株式会社とは関係ありません。
- データはブラウザの localStorage にだけ保存され、外部には送信されません。
